# maya-ceramics-classification
Chemical composition classification of pottery types found at different Maya archaeological sites and subregions throughout Guatemala, Mexico, and Belize. Predicts which locality each test sample comes from by using cross validation and and implementing multiple machine learning algorithms. 

TO DOWNLOAD: 

Download Maya_Pottery_Classification 2.0 files (or the zip file and extract), it contains the excel data and the python files needed. Make sure all of the files are in the same folder or else the Analysis_of_mayan_pottery.py script won't run correctly. Developed in Spyder IDE (recommended for user usage as well).

classification-code.py is an earlier version of this project with only two localities. Use the 2.0 version for more extensive locality classifications.

For a walkthrough of the process used check out the jupyter_walkthrough.ipynb notebook.
