# maya-ceramics-classification
Chemical composition classification of two maya pottery types from different archaeological sites. Determines from which dataset\location each sample comes from by using various machine learning algorithms.  Figured out which models and elements are the best for classification into their respective datasets.
Download Maya_Pottery_Classification 2.0.zip file and extract it (it contains the data and the python files needed). Make sure all of the files are in the same folder or else the (Analysis_of_mayan_pottery.py) file won't run.
